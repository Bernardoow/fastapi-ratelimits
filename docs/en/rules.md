# Rules and identity

A rule describes how much quota a client can spend within a time window. Define
one rate per `limiter.limit(...)` call. For example, `"2/second"`,
`"10 per 2 minutes"`, `"100/hour"`, `"500/day"`, `"1000/month"`, and
`"5000/year"` are valid. The amount and window multiplier must be positive.
See the [rate limit string notation](https://limits.readthedocs.io/en/stable/quickstart.html#rate-limit-string-notation)
for the grammar. Apply multiple windows by declaring one dependency per window.

For each app below, save the block as `app.py` and run
`python -m uvicorn app:app` after following the [quickstart](quickstart.md).
The examples use `X-Account` as demonstration input. In your application,
resolve the account and its tier from authenticated data.

## Choose the client key and route scope

By default, [`key_by_ip`](reference.md#default-identity-and-route-helpers) uses
`request.client.host` and `default_route_id` uses the explicit `operation_id` or
the ID generated by FastAPI. Thus different HTTP methods or route templates
normally have separate quotas, while `/orders/1` and `/orders/2` share the same
operation. Behind a reverse proxy, configure the ASGI server to accept forwarded
client addresses only from proxies you trust.

Set `Limiter(key_func=...)` for the default client identity and
`limiter.limit(..., key_func=...)` for a rule-specific override. Set
`Limiter(route_id_func=...)` to change route scoping. Each function returns a
nonempty string. Here, the two order operations share the logical scope
`orders`. The status operation keeps normal route identification and overrides
the client identity with `key_by_ip`.

```python title="app.py"
from typing import Annotated

from fastapi import Depends, FastAPI, Header, Request

from fastapi_ratelimits import Limiter, default_route_id, key_by_ip


async def account(x_account: Annotated[str, Header(min_length=1)]) -> str:
    return x_account


async def route_scope(request: Request) -> str:
    route_id = await default_route_id(request)
    if route_id in {"list_orders", "create_order"}:
        return "orders"
    return route_id


limiter = Limiter(
    storage_uri="async+memory://",
    key_func=account,
    route_id_func=route_scope,
)
app = FastAPI(lifespan=limiter.lifespan)
per_account = Depends(limiter.limit("1/minute"))


@app.get("/orders", operation_id="list_orders", dependencies=[per_account])
async def list_orders() -> list[str]:
    return []


@app.post("/orders", operation_id="create_order", dependencies=[per_account])
async def create_order() -> dict[str, bool]:
    return {"created": True}


@app.get("/status", dependencies=[Depends(limiter.limit("1/minute", key_func=key_by_ip))])
async def status() -> dict[str, bool]:
    return {"ok": True}
```

```sh
curl -i -H 'X-Account: demo-a' http://127.0.0.1:8000/orders
curl -i -H 'X-Account: demo-a' -X POST http://127.0.0.1:8000/orders
curl -i -H 'X-Account: demo-b' -X POST http://127.0.0.1:8000/orders
```

Expect `200`, `429`, then `200`: `demo-a` spent its order quota, while
`demo-b` has a separate counter. Two requests to `/status` from the same IP
return `200` then `429`, regardless of the `X-Account` header.

## Share a quota and resolve values per request

`group` is a nonempty name that replaces the route scope. Rules share a counter
when their group, client key, strategy, quota amount, and window match in the
same storage namespace. A group uses a separate namespace from route IDs, even
when the names match, and bypasses `route_id_func`.

Use a callable as the first argument of `limit` to choose the rate per request.
Set `cost` to a positive integer or a dependency that returns one. Its default
is `1`. This app uses a shared hourly quota, a dynamic PDF cost validated via
`Query`, and a fixed CSV cost. It also applies a separate per-route quota.

```python title="app.py"
from typing import Annotated

from fastapi import Depends, FastAPI, Header, Query

from fastapi_ratelimits import Limiter


async def account(x_account: Annotated[str, Header(min_length=1)]) -> str:
    return x_account


async def export_quota(user: Annotated[str, Depends(account)]) -> str:
    return "50/hour" if user == "demo-pro" else "5/hour"


async def pdf_cost(pages: Annotated[int, Query(ge=1)] = 1) -> int:
    return pages


limiter = Limiter(storage_uri="async+memory://", key_func=account)
app = FastAPI(lifespan=limiter.lifespan)
per_route = Depends(limiter.limit("20/minute"))
pdf_budget = Depends(limiter.limit(export_quota, group="exports", cost=pdf_cost))
csv_budget = Depends(limiter.limit(export_quota, group="exports", cost=2))


@app.get("/exports/pdf", dependencies=[per_route, pdf_budget])
async def export_pdf() -> dict[str, str]:
    return {"format": "pdf"}


@app.get("/exports/csv", dependencies=[per_route, csv_budget])
async def export_csv() -> dict[str, str]:
    return {"format": "csv"}
```

```sh
curl -i -H 'X-Account: demo-basic' 'http://127.0.0.1:8000/exports/pdf?pages=3'
curl -i -H 'X-Account: demo-basic' http://127.0.0.1:8000/exports/csv
curl -i -H 'X-Account: demo-basic' http://127.0.0.1:8000/exports/csv
curl -i -H 'X-Account: demo-pro' 'http://127.0.0.1:8000/exports/pdf?pages=3'
```

Expect `200`, `200`, `429`, then `200`. The first two requests spend all five
units for `demo-basic`. The higher quota for `demo-pro` allows its PDF request.

FastAPI resolves the providers and their sub-dependencies. Here, the nested
`Depends(account)` and the limiter's `key_func=account` use the same callable,
whose result FastAPI reuses by default within one request. In tests you can
replace it with an async provider using `app.dependency_overrides[account]`.

## Skip a rule conditionally

Set `skip_if` to a boolean or a FastAPI dependency that returns a boolean.
The default is `False`. When the value is `True`, the limiter skips quota
consumption and the statistics lookup for that rule. The rule contributes no
quota headers, and the operation's other rules still apply.

In the previous example, replace the `pdf_budget` definition to exempt an
account from the shared quota on PDF requests. The per-route quota still applies.

```python
async def skip_pdf_budget(user: Annotated[str, Depends(account)]) -> bool:
    return user == "demo-partner"


pdf_budget = Depends(
    limiter.limit(export_quota, group="exports", cost=pdf_cost, skip_if=skip_pdf_budget)
)
```

FastAPI still resolves the rule's dependencies, so an invalid `pages` query
parameter can return `422` for an exempt account. Once the rule is skipped, the
limiter ignores the resolved key, scope, quota, and cost. It validates fixed
values when you call `limit(...)`. A callback that returns a non-boolean value
raises `ValueError`.

## Use an existing synchronous callback

FastAPI runs regular `def` callbacks in a worker thread. Configuring one
directly on the limiter, a rule, or the response-header middleware emits
[`SynchronousCallbackWarning`](reference.md#warnings). Prefer `async def` for
callbacks using asynchronous I/O. To observe the warning, replace
`async def account` with `def account` in either app and restart Uvicorn. The
same HTTP examples still work.

## Order rules that apply to the same operation

List route dependencies in the order you want them checked. The first denial
ends the sequence. Earlier rules keep the quota they already consumed, and
fixed-window counters may also increment on denied attempts. An admitted
request spends quota before either an async or a synchronous endpoint runs.
That quota stays consumed if the endpoint later fails.
