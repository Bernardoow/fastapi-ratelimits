# Rules and identity

## Client identity and route scope

By default, `key_by_ip` uses `request.client.host`. If you run behind a reverse
proxy, configure your ASGI server to accept forwarded client addresses from
trusted proxies only.

The default route identifier is the operation's explicit `operation_id` or the
`unique_id` generated by FastAPI. Use distinct identifiers for operations with
independent quotas. To change route identification, pass `route_id_func` to
`Limiter`. To change client identity, pass `key_func` to `Limiter` or override it
for a rule with `limiter.limit(..., key_func=...)`. Return a nonempty string from
either callback.

## Shared quotas and dynamic costs

Use a `group` to share a quota across routes. The group replaces the route scope
and keeps the client identity. Rules share a counter when they have the same
group, client identity, strategy, quota amount and window in the same storage.

The example gives each account a shared hourly export quota and a separate
per-route limit. The query parameter `items` determines how much of the hourly
quota each export consumes. An individual rule's cost defaults to `1` and can
be a fixed positive integer or a dependency that resolves to one.

```python
from typing import Annotated

from fastapi import Depends, FastAPI, Header, Query

from fastapi_ratelimits import Limiter


async def account(x_account: Annotated[str, Header()]) -> str:
    return x_account


async def export_quota(user: Annotated[str, Depends(account)]) -> str:
    return "1000/hour" if user == "demo-pro" else "100/hour"


async def export_cost(items: Annotated[int, Query(ge=1)] = 1) -> int:
    return items


limiter = Limiter(storage_uri="async+memory://", key_func=account)
app = FastAPI(lifespan=limiter.lifespan)
shared = Depends(limiter.limit(export_quota, group="exports", cost=export_cost))


@app.get("/export/pdf", dependencies=[shared, Depends(limiter.limit("20/minute"))])
async def export_pdf():
    return {"format": "pdf"}


@app.get("/export/csv", dependencies=[shared, Depends(limiter.limit("40/minute"))])
async def export_csv():
    return {"format": "csv"}
```

The example uses `X-Account` to demonstrate identity. In production, derive the
account and quota tier from authenticated application data.

FastAPI resolves `key_func`, `route_id_func`, dynamic limit values, and dynamic
costs as dependencies, including their own dependencies, caching, and
`dependency_overrides`. Prefer `async def` with asynchronous I/O. A `def`
callback runs in a worker thread and emits `SynchronousCallbackWarning` when
configured.

## Rule order and quota consumption

Add one dependency per rule and list them in evaluation order. The first denial
stops the sequence, and any quota already consumed by an earlier rule stays
consumed. The fixed window strategy may also increment its counter on a denied
attempt.

An admitted request consumes quota before the endpoint runs, including for
synchronous endpoints. The cost stays consumed if the endpoint later fails.
Use FastAPI's dependency declarations to choose which rules apply at the app,
router, and route levels.
